### 3.3 导出文件的独立校验

测试 2 导出的文件写到了 `_verification/downloads/roundtrip.xlsx`，再用 openpyxl 独立打开：

联系人: 14 rows x 18 cols
表头: ['姓名','公司/部门','分组','标签','收藏','备注','联系方式1类型','联系方式1号码','联系方式1备注', ...]

## 7. 已知问题与后续

| 问题 | 影响 | 计划 |
| --- | --- | --- |
| 导入判重只按姓名 | 两个同名同姓的人会被合并 | 可在预览里手动「拆成新联系人」 |
| 联系方式类型固定 | 无法新增「钉钉」等类型 | 改成用户自定义类型 + localStorage |
| 大数据量 | 500 条以上卡片渲染会略慢（一次 innerHTML） | 改成虚拟滚动或分页 |
| 没有自动化 UI 测试 | 界面回归靠截图脚本断言 + 人工 | 可引入 Playwright（本作业为保持零依赖未做） |
